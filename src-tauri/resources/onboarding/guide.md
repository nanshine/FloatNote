# 认识 FloatNote 与 Markdown

FloatNote 主要编辑 Markdown 文件，文件后缀是 `.md`。你可以像普通文档一样直接编辑，内容会自动保存到本地；Markdown 用少量符号表达标题、列表和引用，便于在其他支持 Markdown 的编辑器中继续使用。

这个入门项目也是一个普通项目，你可以修改或删除其中的内容。采集区保存材料，写作区形成自己的观点，行动清单记录接下来要做的事；双栏可以让材料和写作并排显示。

## 常用 Markdown 格式

每个示例先展示 Markdown 写法，再展示对应效果。代码块里的符号保留原样，代码块下面是实际排版。

### 标题

写法（井号后面留一个空格）：

```markdown
## 我的观点
### 支持这个观点的理由
```

效果：

## 我的观点

### 支持这个观点的理由

### 粗体与斜体

写法：

```markdown
先写出**核心结论**，再补充*支持它的理由*。
```

效果：

先写出**核心结论**，再补充*支持它的理由*。

### 列表

写法：

```markdown
- 收集材料
- 整理观点

1. 给出结论
2. 说明理由
```

效果：

- 收集材料
- 整理观点

1. 给出结论
2. 说明理由

### 引用

写法：

```markdown
> 让每一段材料，连接到自己的思考。
```

效果：

> 让每一段材料，连接到自己的思考。

### 链接与行内代码

写法：

```markdown
访问 [FloatNote 官网](https://floatnote.ink/)，采集内容保存在 `_inbox.md`。
```

效果：

访问 [FloatNote 官网](https://floatnote.ink/)，采集内容保存在 `_inbox.md`。

### 代码块

用三枚反引号围住多行代码，开头可以注明语言。

写法：

````markdown
```javascript
const thought = "把读到的变成学会的";
console.log(thought);
```
````

效果：

```javascript
const thought = "把读到的变成学会的";
console.log(thought);
```

## 你的内容存在哪里

一个项目就是电脑上的一个文件夹。首次创建时，FloatNote 默认将项目放在当前用户的「文档 / FloatNote」目录，无需手动选择位置；如果已有保存位置，则继续沿用。你也可以从项目菜单选择其他位置新建。

这个项目中有三个 Markdown 文件：

- `_inbox.md`：采集区，保存摘录和灵感。
- `_tasks.md`：行动清单，保存待办事项。
- `FloatNote 入门.md`：你正在阅读的写作文档。

以 `_` 开头的 Markdown 文件供项目的系统功能使用；写作文档不以 `_` 开头，一个项目可以有多篇写作文档。普通新项目的行动清单文件会在添加第一条行动时创建。

点击顶部项目名称，在项目列表中找到当前项目，打开右侧的「⋯」菜单，选择「在 Finder 中显示」（macOS）或「在文件资源管理器中显示」（Windows），即可找到本地项目文件夹。

采集区还可能包含用于标注和来源关联的元数据，编辑正文即可，不必手动修改这些元数据。

## 从自己的项目开始

### 创建一个自己的项目

点击顶部项目名称，再点击项目列表旁的「＋」，选择新建位置并输入项目名称。按主题组织项目，例如“读书笔记”或“产品构思”。

### 创建一篇写作内容

进入自己的项目，切换到「写作」并新建内容，写下标题和第一段观点；之后也可以从写作文档切换菜单继续新建文章。

### 迭代写作的第二个版本

写好初稿后，点击写作栏的「版本」图标，选择「记录当前版本」。继续修改文章，再次「记录当前版本」，就留下了第二个版本；在版本菜单中可以预览或恢复已有版本。自动保存负责保存当前内容，「记录当前版本」用于留下可回看的写作阶段。

完成这些行动后，可以回到本项目的行动清单勾选对应事项。教程会保留在这里，方便随时回看。
